IT-system testbed evaluation: CCD recovery sequence D_1 -> D_2 -> D_3
=====================================================================

Setup. Dockerized IT system with m = 10 web-service replicas n_1..n_10 behind a
load-balancing gateway, backed by a PostgreSQL database n_11; n_1 doubles as a
management host and is compromised (code execution). Detected attacker state
P~ = {P_0, P_1}. Functionality Phi = E[T] + kappa * sum_{i=2}^m A_i -- the expected
total end-to-end throughput plus the availability of the management network, with
kappa = 2 capturing the value of the management functions (bonus 18 when all nine
links A_2..A_10 are open). Critical level alpha = 0.5 * Phi_nominal = 44.50
(Phi_nominal = 71.01 req/s throughput over the 600-window nominal dataset + 18).
The management term is exact per mode (each mode pins the A_i; nominal operation
never closes them), so throughputs are reported unchanged. CCD selects each mode from that
nominal dataset alone (causal inference via do-calculus; the degraded
configurations are confounded with low load in the data, so naive conditioning is
biased). Measurements: 100 windows of 6 s per mode on the live testbed; modes are
enacted with per-container iptables rules (REJECT with tcp-reset).

Mode D_1 -- containment (attack detected, nothing patched yet)
--------------------------------------------------------------
Intervention: do(N_1=0, M_1=0, A_2=0, ..., A_10=0)
  - N_1 = 0: close gateway -> n_1 (removes the compromised server's carried load
    T~_1 from T; the attacker controls T~_1 via P_1).
  - A_i = 0 (i = 2..10): close the management links n_1 -> n_i, blocking the
    lateral-movement exploits E_2..E_10.
  - M_1 = 0: close n_1 -> database, blocking the credential exploit E_11.
Together the closures block all 10 exploits reachable from P~, so the attacker
cannot gain any new privilege (containment criterion holds); N_1=0 disconnects
every attacker-controlled variable from the functionality variable T
(functionality criterion holds).
The mode closes all management links, so Phi carries no management term.
Inferred:  Phi-hat = 65.50 (throughput 65.50 req/s) = 73.6% of nominal (feasible).
Measured:  Phi = 60.53 +/- 6.55 (throughput 60.53 req/s) = 72.9 +/- 7.9% of
           measured nominal (relative error of the throughput inference: 7.6%).

Recovery action 1: patch the lateral-movement vulnerabilities on n_2..n_10 and
the database-credential vulnerability (removes exploits E_2..E_11 from the attack
graph Gamma). The attacker still holds P_1 (code execution on n_1).

Mode D_2 -- less restrictive (exploits patched, attacker still present)
-----------------------------------------------------------------------
Intervention: do(N_1=0)
With E_2..E_11 patched out of Gamma, containment is free: no exploit is feasible
from P~, so the management links A_2..A_10 and the database link M_1 are restored.
Only N_1 stays closed, because the attacker still controls n_1's carried load;
keeping n_1 out of the load-balancing pool keeps the attacker disconnected from T.
D_2 is strictly less restrictive than D_1 (D_1 superset D_2).
Restoring the management links regains the kappa-term (+18), which now separates
D_2 from D_1 in functionality, not only in restrictiveness.
Inferred:  Phi-hat = 81.39 (throughput 63.39 req/s + 18) = 91.4% of nominal (feasible).
Measured:  Phi = 82.09 +/- 5.86 (throughput 64.09 req/s + 18) = 98.9 +/- 7.1% of
           measured nominal (relative error of the throughput inference: 1.1%).

Recovery action 2: evict the attacker -- re-image n_1, which removes the foothold
vulnerability (patches E_1) and shrinks the detected state to P~ = {P_0}.

Mode D_3 -- full restoration (attacker evicted)
-----------------------------------------------
Intervention: do() (empty)
With the attacker evicted, no exploit is feasible and the derived set of
attacker-controlled variables is empty; both criteria hold with no closures, so
CCD returns the empty intervention and all links are restored.
Inferred:  Phi-hat = 86.21 (throughput 68.21 req/s + 18) = 96.9% of nominal (feasible).
Measured:  Phi = 88.56 +/- 6.30 (throughput 70.56 req/s + 18) = 106.7 +/- 7.6% of
           measured nominal (relative error of the throughput inference: 3.4%).

Estimands
---------
Observational estimands (after identification) used for the inferred Phi of each
mode. The workload W is the confounder -- maintenance closures are likelier at low
load -- and it satisfies the backdoor criterion for the link interventions, so each
interventional mean is identified by adjusting for W: condition on the pinned link
states and W, then average W over its marginal distribution p(w) (not over the
low-load subpopulation in which closures happen to occur). The A_i have no causal
edges into the throughput subsystem, so they enter only through the deterministic
kappa-term (kappa * number of open links; + 18 when all nine are open):

  Nominal:      Phi = E{T} + 18
  D_1:          Phi = int E{T | N_1=0, M_1=0, W=w} p(w) dw + 0
  D_2:          Phi = int E{T | N_1=0, W=w} p(w) dw + 18
  D_3:          Phi = E{T} + 18                     (empty intervention)
  Containment:  Phi = int E{T | M_1=0, W=w} p(w) dw + 0
  Attack:       Phi = 0 + 18                        (no estimation needed:
                T = sum_i N_i * T~_i with all T~_i = 0, exact by the known F~)

In practice each adjustment integral is evaluated by the fitted SCM on the
throughput subgraph (the g-formula over the causal graph, with the gated products
T_i = N_i * T~_i as exact mechanisms and the remaining mechanisms learned):
interventional samples draw W and the noise terms from their observational
distributions, pin the mode's links, and propagate. The adjustment is what removes
the confounding: the unadjusted conditional E{T | N_1=0, M_1=0} (44.30 req/s) is
biased low versus the adjusted estimate (65.50 req/s) because it averages only
low-load windows.

Baselines (model-derived; shown in the inferred bar group only, since the attacker
software is not implemented on the testbed and neither baseline can be measured)
---------------------------------------------------------------------------------
- No degradation ("Attack"): the attack propagates fully -- the attacker gains
  code execution on every server and the database and zeroes every carried load
  T~_i, so T = sum_i N_i * T~_i = 0 exactly by the known functions F~. The
  operator closes nothing, so the management links remain open and the
  kappa-term survives: Phi_attack = 18.00 (throughput 0) = 20.2% of nominal --
  total loss of throughput, well below the critical level alpha.
- Naive containment ("Contain"): apply every blocking-edge closure regardless of
  functionality: do(M_1=0, A_2..A_10=0). The throughput impact is the loss of
  server 1's database access (throughput 64.19 req/s, estimated from the nominal
  dataset; cached in data/baseline_containment.json), and closing every
  management link forfeits the whole kappa-term, so Phi = 64.19 = 72.1% of
  nominal. Unlike CCD it never restores -- it stays at 72.1% for the whole
  incident while CCD relaxes to D_2 (91.4%) and D_3 (96.9%) -- and it leaves
  the attacker in control of T~_1 without the N_1 closure that CCD adds to
  guarantee the functionality criterion.

Notes
-----
- The mode sequence is monotone (D_1 superset D_2 superset D_3 = empty): each
  recovery action only removes attack-graph edges / shrinks P~, and CCD re-solves
  the same problem; the model, not the algorithm, encodes the recovery.
- % of nominal: inferred bars are normalized by Phi_nominal = 89.01 (throughput
  71.01 req/s over the nominal dataset + 18); measured bars by the measured
  nominal run (Phi = 83.01: throughput 65.01 +/- 7.14 req/s over 100 windows
  + 18). Workload is random (W ~ U[50, 150] req/s per window), so per-run means
  fluctuate: D_2 and D_3 measuring slightly above their inferred values (and D_3
  above 100%) is within the 95% confidence intervals, which overlap nominal for
  D_2/D_3.
- All three modes satisfy Phi >= alpha (= 50% of nominal) in both the inferred
  and the measured columns. The throughput loss under containment-style closures
  is approximately 1/m, matching the analytic (m-1)/m = 90% at m = 10; the
  functionality ordering is attack (20.2) < containment (72.1) ~ D_1 (73.6) <
  D_2 (91.4) < D_3 (96.9) < nominal -- D_1 and containment remain close because
  both close all management links; the kappa-term is what separates D_2 from D_1,
  and the attack baseline alone falls below alpha.
